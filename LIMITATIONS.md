# Limitations

## Sample Size
- Small samples (2-50 trials per condition)
- Not statistically significant
- No power analysis

## Classification
- Rule-based (regex), not human-validated
- No inter-annotator agreement
- Edge cases may be miscategorized

## Model Coverage
- Only 2 models tested
- Both from Groq free tier
- No GPT-4, Claude, Gemini, or Llama

## Question Set
- All questions in English
- Most about Algeria
- Small pool (10-20 questions)
- No random sampling

## Parameters
- temperature=0.0 for most tests
- max_tokens varied (500-800)
- Rate limits caused some failures

## Generalization
- Results apply only to these models
- Only to these questions
- Only at this date (October 2026)
- Do not generalize

## What Would Be Needed
1. Larger sample (100+ trials)
2. Multiple models (5+ per family)
3. Multiple languages
4. Random sampling
5. Human validation
6. Pre-registration
7. Statistical tests
8. Peer review
